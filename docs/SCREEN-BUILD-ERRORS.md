# Ошибки при сборке экранов — чтобы не повторять

Журнал ошибок. Первая запись — тестовый прогон «Account / Affiliate program» (2026-10-29). Дополняется после каждого экрана.

Главное правило: **экран собирается только из наших компонентов и токенов. Макет Figma даёт логику и вид, но не состав.** Если макет и система расходятся — права система; недостающее — новый компонент системы или вопрос владельцу, а не одноразовая верстка и не догадка.
